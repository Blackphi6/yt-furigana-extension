〜

    Super Chat と通常チャットのふりがなは個別にオン／オフできます。 「スパチャのみ表示」は通常チャット行を隠します（既定 Ctrl+Shift+L）。 台帳は DOM からセッション内だけ蓄積し、サーバーへ送りません。 視聴ページの累積パネルは ×、またはここの「累積パネル」オフ／台帳の × で閉じられます（既定オフ）。 配信中の「開始〜今まで取得」とアーカイブの「全件取得」はチャット再生 API を手動で低頻度に使います（字幕 API は不使用）。巻き戻しできない配信の過去分は取れません。 タイムコードがある行はクリックでシーク、ダウンロードボタンで1枚PNG保存できます。 読み API は任意オプトインです（オフ＝端末内のみ）。 YouTube timedtext は使いません。
