--------------------------------------------------------------------------------
【詳細説明】（そのまま貼る）
--------------------------------------------------------------------------------
YT Live Chat Furigana は、YouTube ライブ配信（およびアーカイブ）の Super Chat と通常ライブチャット本文に、ひらがなのふりがな（ruby）を重ねて表示する Chrome 拡張です。

【できること】
・Super Chat のメッセージ本文へルビを付ける
・上部ティッカーに流れる Super Chat 文言にも対応
・通常ライブチャットのメッセージ本文へルビを付ける
・Super Chat と通常チャットはポップアップで個別にオン／オフ
・「スパチャのみ表示」で通常チャット行を隠す（Stylus 相当。既定ショートカット Ctrl+Shift+L）
・StreamYard ステージ上のコメントバナーにも対応（通常チャット側）
・処理はすべて端末内（kuromoji）。外部サーバーへチャット本文を送りません
・読みが付かない漢字はクリックして手動登録（端末内保存）

【やらないこと】
・動画ページ下のコメント欄へのルビ
・YouTube timedtext / 字幕配信 API へのアクセス
・広告・トラッキング
