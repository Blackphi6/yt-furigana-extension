YT Live Chat Furigana

YouTube ライブ配信の Super Chat（と上部ティッカー）および 通常ライブチャットに、ひらがなのふりがなを付ける非公式 Chrome 拡張です。 字幕向けの YT Furigana とは別インストールです。

特徴

  • Super Chat / ティッカーと通常チャット（個別にオン／オフ）
  • 「スパチャのみ表示」で通常チャット行を隠せる（Stylus 相当）
  • 端末内の辞書（kuromoji）だけで処理。チャット本文をサーバーへ送らない
  • YouTube timedtext / 字幕 API は使わない
  • 動画ページ下のコメント欄は対象外

StreamYard で視聴者にも見せる

拡張の DOM 書き換えは配信映像に乗りません。視聴者向けには ルビオーバーレイページ をブラウザで開き、StreamYard の画面共有／プレゼンでそのタブをステージに載せてください（手動配置）。

インストール

Chrome Web Store 公開後は、下のボタンから追加できます。公開前は zip / ソースから読み込んでください。

Chrome に追加

A. 提出用 zip（ローカル読み込み）

  1. リポジトリで npm run pack:superchat を実行し、 store/superchat-cws-upload/yt-superchat-furigana.zip を展開
  2. chrome://extensions → デベロッパーモード → パッケージ化されていない拡張機能を読み込む
  3. 展開したフォルダを選ぶ

B. ソースからビルド

  1. npm install && npm run superchat:build
  2. extensions/yt-superchat-furigana を読み込む

使い方

  1. YouTube ライブ（またはアーカイブ）でチャットを表示
  2. 拡張アイコンで「Super Chat / ティッカー」「通常チャット」を必要に応じてオン
  3. 必要なら「スパチャのみ表示」をオン（通常チャット行を非表示）
  4. 対象のメッセージ本文にルビが付く
  5. 読みが付かない漢字はクリックして手動登録（端末内に保存）
