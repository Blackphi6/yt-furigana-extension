プライバシーポリシー

最終更新: 2026-07-31

対象: YT Super Chat Furigana（Chrome 拡張）。 字幕向けの YT Furigana 本体とは別製品です。本体のポリシーは こちら。 本文書は法的助言ではありません。

1. 運営

  • リポジトリ: https://github.com/Blackphi6/yt-furigana-extension
  • 連絡: GitHub Issues

2. 収集するデータ

開発者のサーバーへ Super Chat 本文や視聴データを送信しません。

  • 拡張は、開いている YouTube ページ上の Super Chat（および上部ティッカー）の 画面上の DOM テキストを読み、端末内の辞書でルビ付き HTML に変換して同じ要素へ戻します。
  • オン／オフ設定と、ユーザーが手動登録した読みは chrome.storage.local に端末内保存します（サーバーへ送りません）。
  • アカウント情報・位置情報・閲覧履歴リストは収集しません。

3. 権限

  • storage … 設定・手動登録読みの端末内保存
  • youtube.com / m.youtube.com … ライブチャット（iframe 含む）内の Super Chat DOM へアクセスするため

YouTube timedtext / 字幕配信 API は使用しません。

4. 第三者

本拡張の既定動作では、第三者へユーザーのチャット本文を転送しません。 配布は Chrome Web Store 経由の場合、ストアのポリシーが別途適用されます。

5. 子どものプライバシー

13 歳未満を対象としたサービスではありません。

6. 変更

本ポリシーを更新した場合、本ページの「最終更新」日付を改めます。

7. 連絡

GitHub Issues にて受け付けます。
