プライバシーポリシー

最終更新: 2026-08-08

対象: YT Live Chat Furigana（Chrome 拡張。旧称 YT Super Chat Furigana）。 字幕向けの YT Furigana 本体とは別製品です。本体のポリシーは こちら。 本文書は法的助言ではありません。

1. 運営

  • リポジトリ: https://github.com/Blackphi6/yt-furigana-extension
  • 連絡: GitHub Issues

2. 収集するデータ

開発者のサーバーへチャット本文や視聴データを送信しません。

  • 拡張は、開いている YouTube ページ上の Super Chat（および上部ティッカー）と 通常ライブチャットの 画面上の DOM テキストを読み、端末内の辞書でルビ付き HTML に変換して同じ要素へ戻します。
  • Super Chat / 通常チャットの個別オン／オフ設定と、ユーザーが手動登録した読みは chrome.storage.local に端末内保存します（サーバーへ送りません）。
  • 「スパチャ台帳」は、拡張が動作中に画面上に流れた Super Chat の投稿者・金額・本文・時刻を chrome.storage.session に一時保存します（ブラウザ終了で消え、サーバーへ送りません）。
  • アーカイブ動画でユーザーが「全件取得」を押したときだけ、YouTube のチャット再生と同じ get_live_chat_replay 経路で Super Chat を端末内に取り込みます（開発者サーバーへは送りません。 timedtext / 字幕 API は使いません）。取得結果もセッション台帳に保持します。
  • タイムコード付きカード画像（PNG）は端末内で生成し、ユーザーのダウンロードフォルダへ保存します。
  • アカウント情報・位置情報・閲覧履歴リストは収集しません。

3. 権限

  • storage … 設定・手動登録読み・セッション台帳の端末内保存
  • youtube.com / m.youtube.com … ライブチャット（iframe 含む）内のチャット DOM へアクセスするため
  • streamyard.com … StreamYard スタジオ上のステージコメントバナー DOM へアクセスするため

YouTube timedtext / 字幕配信 API は使用しません。動画ページ下のコメント欄は対象外です。

4. 第三者

本拡張の既定動作では、第三者へユーザーのチャット本文を転送しません。 配布は Chrome Web Store 経由の場合、ストアのポリシーが別途適用されます。

5. 子どものプライバシー

13 歳未満を対象としたサービスではありません。

6. 変更

本ポリシーを更新した場合、本ページの「最終更新」日付を改めます。

7. 連絡

GitHub Issues にて受け付けます。
