Privacy Policy

Last updated: 2026-07-25

This is not legal advice. Japanese version: privacy.html

1. Operator

Repository: GitHub. Contact: GitHub Issues.

2. Default (Free) data

By default (Free, “Standard” or “High accuracy” engines), we do not send caption body text to our servers.

  • Settings → chrome.storage.sync
  • License / API keys, reading dictionary, learning inbox → chrome.storage.local (learning inbox opt-out available)
  • Shared readings pack receive (default on, can disable): surface→reading only from the public reading API. No caption body.

On YouTube / TVer we read on-screen caption DOM only. Default playback does not call YouTube timedtext.

3. Optional sends

3.1 Public reading API (opt-in)

Enabled when you choose “Accuracy first” on first popup open, or later select “Public reading API” in advanced engine settings. Until then the extension stays on-device (no caption body leaves the device). Selecting accuracy / public API counts as consent to send on-screen caption text for reading estimation. You can switch back to on-device anytime.

  • Destination: public reading engine by default (https://yt-furigana-readings.onrender.com), or a URL you set
  • Sent: on-screen caption text; personal reading dictionary entries if any
  • Not sent: video URL, watch history, comments, account info, persistent device IDs
  • Purpose: furigana / reading estimation only

3.2 Other optional sends

  • BYO reading API / Ollama: only if you configure them
  • Premium sync / server shared dict: user-configured server
  • Anonymous corrections (opt-in): surface, reading, and short context only (no video URL). Enabled only when the user turns it on (including a one-time prompt after the first correction). Public /v1/contribution-stats exposes surface, reading, and vote counts only — no context, voter IDs, or IPs
  • Demo reading proposals (optional): surface→reading only into a review queue — not published to the Free pack until curated after heuristic / optional LLM review
  • Stripe checkout (site): payment via Stripe

Public API may rate-limit by IP. Opt-in votes and demo proposals use a non-reversible voter id derived from IP (not published in the pack or /v1/contribution-stats).

4. Ads / tracking

No ad SDK or behavioral tracking in the extension.

5. Children

Not directed at children under 13.

6. Deletion

Uninstall the extension or clear extension storage. Disable shared pack receive in the popup. Server-hosted Premium data follows the server operator’s process.
