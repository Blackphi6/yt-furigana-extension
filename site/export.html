日本語の手動字幕 ルビ対応形式のみ 非公式

字幕にふりがなを振って書き出す。

YouTube の日本語字幕を読み込み、漢字にルビを付けて WebVTT / SRV3 / TTML で保存します。 ルビを文字の上に載せられる形式だけを対象にしているため、SRT には対応していません。

1. 字幕を読み込む

対象は日本語の手動字幕のみです。自動生成（音声認識）字幕と、字幕が無い動画は対象外にしています。

取得には YT Furigana 拡張 1.9.1 以降が必要です（拡張があなたのブラウザで 1 本ずつ取得します）。 Chrome ウェブストアの古い版（1.9.0）にはこの橋渡しがありません。

拡張が見つからない・反応しないとき

1. chrome://extensions で YT Furigana がオンか確認
2. バージョンが 1.9.1 以上か確認（未満なら下の手順で差し替え）
3. 未公開ビルドを使う場合は、同じ画面の ID を下に貼って保存（この端末のみ）

拡張を入れたくない場合は「字幕ファイルを貼る」タブを使ってください。ネットワークに一切アクセスしません。

2. ふりがなを付ける

公開読み API に本文を送って読みを取得します（無料枠のため、初回は起動待ちで数十秒かかることがあります）。
